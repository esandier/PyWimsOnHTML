PWOH (PyWimsOnHTML) prend en entrée un fichier descriptif à base de code Python pour la logique de la question et de HTML pour son aspect visuel, et produit un fichier HTML autonome qui peut être déposé tel quel sur Moodle, ou distribué par courriel… Il peut également créer un paquet SCORM, qui permet sur Moodle de suivre l'activité des étudiants sur le(s) exercices interactifs.

Pour l'utilisateur (élève ou étudiant) : un outil d'entraînement.

  • Chaque question affiche à la demande les erreurs dans les réponses et/ou la réponse correcte.
  • La question est considérée faite à la première réponse correcte, mais possibilité de recommencer à volonté.
  • La progression est enregistrée d'une session à l'autre.
  • Bonne ergonomie sur un téléphone.

Pour l’enseignant

  • Les codes sources des questions et la charte graphique sont sur son ordinateur. Aucune donnée n'est conservée.
  • Pas besoin de compte ni d’inscription. Aucun programme à télécharger.
  • Une charte graphique en .css peut accompagner les questions, pour un visuel cohérent entre elles propre à l'établissement, par exemple.
  • Dans le cas d'un export sous forme de paquet SCORM, possibilité de suivre l’activité des élèves ou étudiants.
  • Outil pour l’entraînement uniquement : un utilisateur motivé peut en principe retrouver les solutions dans le fichier.

Pour commencer

  1. Créez un dossier pour vos questions.
  2. Créez une question, à l’aide d’une IA de votre choix ou à partir d’un modèle.
  3. Ouvrez votre dossier de questions dans l’atelier.
  4. Choisissez la ou les questions à exporter, cliquez sur « Exporter la sélection » : la page HTML ou le paquet SCORM est téléchargé, ou des messages d’erreur sont affichés.
  5. Déposez sur Moodle, ou partagez.
