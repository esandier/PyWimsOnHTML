Créer un exercice

Un exercice est un petit fichier texte, d’extension .pwq. On l’écrit avec l’aide d’une IA, ou à la main à partir d’un modèle, puis le compilateur en fait une page HTML à donner aux élèves.

  2. Sans IA : le format .pwq
  3. Les champs de réponse

1. Avec une IA

Le prompt explique le format à l’assistant (ChatGPT, Claude, Le Chat…) : il écrit alors un fichier complet et correct.

  1. Copiez le prompt, et collez-le au début d’une conversation avec votre assistant.
  2. Décrivez l’exercice voulu : « un QCM sur la dérivée de x ↦ ax² + bx, avec des valeurs tirées au hasard », ou collez une question d’AMC à convertir.
  3. Enregistrez la réponse dans un fichier .pwq de votre dossier d’exercices, puis ouvrez ce dossier dans le compilateur : l’aperçu montre l’exercice, et signale une erreur s’il y en a une.
Voir le prompt

Relisez toujours l’exercice produit : le compilateur vérifie que la solution est jugée juste, pas que l’énoncé est mathématiquement correct.

2. Sans IA : le format .pwq

Le plus simple est de partir d’un modèle commenté, de le copier dans votre dossier d’exercices et de le modifier :

QCM

Des choix, dont un bon, mélangés à chaque tirage ; sans aléatoire ni Python à écrire.

Télécharger qcm.pwq

Réponse calculée

Des valeurs tirées au hasard et une réponse calculée en Python, à écrire dans un champ.

Télécharger calcul.pwq

Structure d’un fichier

Un fichier est une suite de champs. Chacun commence par trois lignes : %, % nom_du_champ, % ; son contenu suit. Une ligne % seule ferme le dernier champ. Voici le modèle « réponse calculée » en entier :

%
% title
%
Modèle : réponse calculée
%
% keywords
%
modèle, calcul, aléatoire
%
% layout
%
STD
%
% avant
%
from random import randint
a = randint(2, 9)
b = randint(11, 19)
produit = a * b
explication_solution = rf"${a}\times {b} = {produit}$."
%
% enonce
%
Calculez ${{a}} \times {{b}}$ :
{% input_text 'reponse' solution=produit style='width:4em' %}
%
ChampStatutContenu
titleobligatoiretitre de l’exercice, affiché aux élèves
keywordsobligatoiremots-clés séparés par des virgules (recherche dans le compilateur)
layoutobligatoiretoujours STD
avantobligatoirecode Python : tirage des valeurs et calcul des solutions
enonceobligatoireénoncé en HTML, avec formules, valeurs {{variable}} et champs de réponse
apresfacultatifcode Python de correction, pour accepter plusieurs écritures ou donner un retour ciblé
tiragesfacultatifnombre de tirages préparés, de 1 à 200 (20 par défaut)

Le champ avant

  • C’est du Python. Importez ce dont vous avez besoin (from random import randint, from sympy import *…). Tirez le hasard avec le module random seulement : le compilateur prépare 20 tirages, et la page les rejoue à l’identique.
  • Une chaîne qui contient une formule s’écrit avec r devant les guillemets (r"$\frac{1}{2}$"), à cause des barres obliques ; avec des valeurs à insérer, rf"${a}\times {b}$".
  • Facultatif : explication_solution, un texte affiché avec la solution (formules admises, et les balises <b>, <i>, <br>).

Le champ enonce

  • Du texte et du HTML ; les formules s’écrivent en LaTeX entre $…$ (dans la ligne) ou $$…$$ (centrées).
  • {{nom}} affiche la valeur d’une variable de avant ; une expression SymPy s’affiche en LaTeX, à mettre donc dans une formule : $f(x) = {{f}}$. Dans une commande LaTeX, laissez des espaces autour : \frac{ {{n}} }{ {{m}} }.
  • Les champs de réponse sont des balises {% … %}, détaillées ci-dessous.

La correction

  • Sans apres (le cas courant) : la réponse de l’élève est comparée à la solution, telle que l’affiche le bouton « Solution ». Seuls les espaces, le signe moins « − » et le codage des accents sont ignorés : 7/12 est faux si la solution est 14/24, 0,5 faux si c’est 0.5. C’est parfait pour un QCM, un entier, un mot.
  • Avec apres : du Python qui reçoit la saisie de chaque champ dans la variable de même nom, et décide ok_answer['nom'] = True ou False ; il peut aussi définir feedback, un retour qui explique l’erreur sans donner la réponse. Il est nécessaire pour une formule (input_math) ou plusieurs écritures justes. Le prompt en donne des exemples.

3. Les champs de réponse

Un champ s’écrit dans enonce, à l’endroit où il doit apparaître :

{% type 'nom' paramètre=valeur paramètre=valeur … %}
  • 'nom' : un nom de variable Python (lettres, chiffres, _), différent des variables de avant ; dans apres, la saisie arrive dans cette variable.
  • Une valeur est un nom de variable de avant (solution=produit), un entier (columns=4) ou un texte entre apostrophes (style='width:4em').
  • solution= est obligatoire pour tous les champs : la variable qui contient la bonne réponse.

input_text : réponse écrite

{% input_text 'reponse' solution=produit style='width:4em' %}
ParamètreStatutRôle
solutionobligatoirenombre, expression SymPy ou texte ; affiché comme un élève l’écrirait (19/12, x^2 + 1). Pour un décimal à virgule, utilisez decimal_fr du module pywims.
stylefacultatifstyle CSS du champ, le plus souvent sa largeur : 'width:4em'

Dans apres, la saisie arrive comme un texte.

input_math : formule, avec clavier mathématique

{% input_math 'derivee' solution=f_prime %}
ParamètreStatutRôle
solutionobligatoireexpression SymPy, affichée en formule

L’élève écrit avec un clavier mathématique (MathLive). Ce champ exige un apres : la saisie y arrive en écriture texte (x^2+1), à lire avec math_expression puis à comparer, par exemple simplify(math_expression(derivee) - f_prime) == 0.

input_matrix : matrice de taille fixe

{% input_matrix 'M' rows=2 cols=3 solution=produit input_style='width:2.5em' %}
ParamètreStatutRôle
solutionobligatoireMatrix SymPy ou liste de lignes
sizel’un ou l’autrematrice carrée size × size
rows, colsnombre de lignes et de colonnes
input_stylefacultatifstyle CSS de chaque case (largeur 2em par défaut)

Les dimensions sont des entiers de 1 à 10, ou des variables de avant. Dans apres, la saisie arrive comme une liste de lignes de textes ; chaque case se corrige à part : ok_answer["M[0][1]"] = ….

input_vmatrix : matrice dont l’élève choisit la taille

{% input_vmatrix 'M' max_rows=5 max_cols=5 solution=produit %}
ParamètreStatutRôle
solutionobligatoireMatrix SymPy ou liste de lignes ; la solution affichée prend ses dimensions
max_rows, max_colsfacultatiftaille maximale (10 par défaut)
input_stylefacultatifstyle CSS de chaque case
cell_width, cell_heightfacultatiftaille imposée des cases, par exemple '3em'

L’élève agrandit ou réduit la grille avec une poignée (ou les flèches du clavier). Sans apres, une grille aux mauvaises dimensions est fausse.

input_radio et input_checkbox : choix unique, choix multiple

{% input_radio 'reponse' choices=choix solution=bonne columns=4 fixed_last=1 %}
{% input_checkbox 'reponses' choices=choix solution=bonnes bareme='b=1,m=-0.5' %}
ParamètreStatutRôle
choicesobligatoireliste de avant : au moins deux choix, dans votre ordre (textes avec formules, ou expressions SymPy)
solutionobligatoireinput_radio : le numéro du bon choix ; input_checkbox : la liste des numéros des bons choix, éventuellement vide. Les numéros commencent à 0.
columnsfacultatifnombre de colonnes sur grand écran, de 1 (par défaut) à 6 ; réservé aux choix courts. Sur téléphone, les colonnes se réduisent d’elles-mêmes.
fixed_lastfacultatifnombre de derniers choix laissés à la fin, non mélangés (0 par défaut) : pour « Aucune de ces réponses ».
baremefacultatifnote indicative, dans la syntaxe d’AMC (voir ci-dessous)

Les choix sont mélangés à chaque tirage. Aucun choix n’est ajouté automatiquement : pour « Aucune de ces réponses », écrivez-le en dernier, avec fixed_last=1. Dans apres, la saisie arrive comme le numéro choisi (choix unique) ou la liste croissante des numéros cochés.

Le barème (questions à choix)

Il affiche une note indicative à chaque vérification, sans rien évaluer. La syntaxe est celle d’AMC, et un barème d’AMC se recopie tel quel : bareme='b=1,m=-0.5,p=0'. Un barème n’est admis que si le champ à choix est le seul champ de la question.

DirectiveRôle
b, mpoints d’une bonne, d’une mauvaise réponse (par case, en choix multiple) ; 1 et 0 par défaut
vpoints si rien n’est coché
ddécalage ajouté au score
p, Pplancher, plafond
mztout ou rien : mz points si tout est juste, 0 sinon
haut, MAXcomme dans AMC
eaccepté, sans effet

Plusieurs réponses justes : LIBRE

Dans une solution, LIBRE (de from pywims import LIBRE) marque une valeur quelconque : toute réponse y est juste, et le bouton « Solution » y affiche « ∗ ». Par exemple, pour une matrice triangulaire : Matrix(n, n, lambda i, j: 0 if i > j else LIBRE).

4. Compiler et publier

  1. Ouvrez le compilateur et choisissez votre dossier d’exercices (ses sous-dossiers sont lus aussi). Sur Chrome et Edge, il est mémorisé pour la visite suivante.
  2. Cliquez sur un exercice pour le voir. Cochez ceux à compiler, puis Compiler : un exercice donne un fichier HTML ; plusieurs, une activité (une seule page, dans l’ordre où vous les avez cochés) ou des pages séparées (archive ZIP).
  3. Sur Moodle, ajoutez une ressource Fichier et déposez-y le fichier HTML : les élèves l’ouvrent dans leur navigateur, sur ordinateur ou téléphone. Vous pouvez aussi l’envoyer par courriel.

Votre charte : les feuilles ont une apparence neutre. Pour les couleurs et le logo de votre établissement, placez un fichier brand.css à la racine de votre dossier d’exercices ; celui de l’UPEC sert d’exemple.

5. Bon à savoir

Pour l’entraînement, pas pour l’évaluation. La correction se fait dans le navigateur de l’élève : les solutions sont lisibles dans le code de la page, et la note n’est qu’indicative.

  • Une question sans apres se corrige sans Python : la page reste légère. Une question avec apres charge Python (environ 10 Mo) au premier contact de l’élève.
  • Edge peut rendre la compilation très lente : sa « sécurité renforcée » ralentit Python sur les sites peu visités. Dans edge://settings/privacy, rubrique « Améliorez votre sécurité sur le web », ajoutez une exception pour https://esandier.github.io.
  • Le compilateur prépare 20 tirages par question ; « Nouvel énoncé » en propose un autre à l’élève. Le champ tirages change ce nombre.
  • La référence complète du format est le prompt : il s’adresse à une IA, mais se lit aussi très bien.
