PWOH questions à données aléatoires dans une page HTML
Accueil Créer Compilateur Code source

PWOH (PyWimsOnHTML) prend en entrée un fichier descriptif simple, à base de code Python pour la logique de la question, et de HTML pour son aspect visuel, et produit un fichier HTML autonome qui peut être déposé tel quel sur Moodle, ou distribué par courriel…

Pour l’élève ou l’étudiant

  • Sa progression dans l’activité est gardée, s’il la reprend après avoir fermé le navigateur.
  • Les données restent dans son navigateur.
  • Ses scores et son activité restent connus de lui seul.
  • Bonne ergonomie sur un téléphone.
  • Chaque question contient sa solution.

Pour l’enseignant

  • Une charte graphique en .css peut accompagner les questions, pour un visuel cohérent entre elles.
  • Les codes sources des questions, des activités et de la charte graphique restent sur son ordinateur.
  • Pas besoin de compte ni d’inscription. Aucun programme à télécharger.
  • L’activité de l’élève ou de l’étudiant et ses scores restent connus de lui seul.
  • Chaque question doit contenir sa solution. C’est un outil pour l’entraînement uniquement.

Pour commencer

  1. Créez un dossier pour vos questions.
  2. Créez une question, à l’aide d’une IA de votre choix ou à partir d’un modèle.
  3. Ouvrez votre dossier de questions dans la page du compilateur.
  4. Choisissez la ou les questions à compiler, cliquez sur « Compiler la sélection » : la page HTML correspondante est téléchargée (ou des messages d’erreur sont affichés).
  5. Déposez votre page sur Moodle, ou partagez-la.
