qu’elle soit triangulaire supérieure, et de rang égal à ${{ size }}$.

Les coefficients notés '*' peuvent être n’importe quel nombre. Les coefficients  situés sous la diagonale doivent être nuls.<br>
Les coefficients situées sur la diagonale sont arbitraires, mais doivent être non nuls car, pour une matrice triangulaire $n\times n$, on a 
$$\text{rang} = n\iff \text{coefficients diagonaux non nuls}.$$
(dans ce cas, le déterminant est le produit des coefficients diagonaux)
# Vérifie chaque case : toute valeur est numérique, et celles sous la diagonale sont nulles.
# Chaque case est vérifiée (pas de break) pour que toutes les cases fausses soient colorées ;
# chaque message n'est ajouté qu'une fois, même si plusieurs cases sont fausses.
messages = []

def add_message(text):
    if text not in messages:
        messages.append(text)

for i in range(size):
    for j in range(size):
        value = py_wims(matrix[i][j])
        is_number = value is not None and value.is_number
        if i > j:
            correct = is_number and value == 0
            message = "Les coefficients sous la diagonale doivent être nuls."
        elif i == j:
            correct = is_number and value != 0
            message = "Les coefficients diagonaux doivent être des nombres différents de zéro."
        else:
            correct = is_number
            message = "Tous les coefficients doivent être des nombres."
        ok_answer[f"matrix[{i}][{j}]"] = correct
        if not correct:
            add_message(message)

if messages:
    feedback = "<br>".join(messages)
