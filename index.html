Des exercices de mathématiques aléatoires, en une seule page HTML

Chaque exercice est tiré au hasard et corrigé dans le navigateur de l’élève : on dépose le fichier sur Moodle, ou on l’envoie, et les élèves s’entraînent, sur ordinateur comme sur téléphone, sans rien demander à personne.

Toujours un nouvel énoncé

Les valeurs sont tirées au hasard : « Nouvel énoncé » propose la même question avec d’autres nombres, autant de fois qu’on veut.

Un fichier, rien d’autre

Ni serveur, ni compte, ni installation : une page HTML qui s’ouvre dans n’importe quel navigateur, et se dépose sur Moodle comme un simple fichier.

Correction immédiate

Champs verts ou rouges, commentaire, solution et explication ; la progression de la feuille est gardée sur l’appareil de l’élève.

Écrit en Python

Les exercices s’écrivent en Python avec SymPy, à la main à partir d’un modèle, ou avec l’aide d’une IA qui suit un prompt fourni.

Démonstrations

De vraies feuilles, produites par le compilateur : répondez, vérifiez, demandez la solution ou un nouvel énoncé.

Pour l’entraînement

La correction se fait chez l’élève : les solutions sont lisibles dans le code de la page, et la note affichée n’est qu’indicative. PyWimsOnHTML sert à s’entraîner, pas à évaluer.

Commencer

  1. Créez un exercice : avec une IA, en copiant le prompt fourni, ou à la main à partir d’un modèle.
  2. Ouvrez votre dossier d’exercices dans le compilateur : l’aperçu montre chaque exercice, la compilation produit la page HTML.
  3. Déposez la page sur Moodle, ou envoyez-la à vos élèves.
