from random import choice
from sympy import *
from pywims import py_wims

# Choisit deux fractions irréductibles, numérateurs et dénominateurs entre 2 et 5.
irreducible_fractions = [(a, b) for a in range(2, 6) for b in range(2, 6) if gcd(a, b) == 1]
n, m = choice(irreducible_fractions)
p, q = choice(irreducible_fractions)
total = Rational(n, m) + Rational(p, q)

# Réduction au même dénominateur, pour l’explication de la solution.
common = ilcm(m, q)
n_common = n * (common // m)
p_common = p * (common // q)
numerator_sum = n_common + p_common
# Dernière égalité, seulement si la fraction obtenue se simplifie.
simplified = "" if total.q == common else " = " + latex(total)

b = randint(-5, 5)
c = randint(-5, 5)
d = randint(-5, 5)
function = expand(a*x**3 + b*x**2 + c*x + d)

Le pourcentage

  • Une question complétée avec « Solution » n’est pas comptée.
  • Une réussite reste acquise, même si vous demandez ensuite un nouvel énoncé.
  • Toutes les questions ont le même poids.

La note

Une question notée affiche, en bas à droite, la note que votre réponse obtiendrait à l’examen selon son barème. Elle change à chaque vérification : c’est une indication pour vous entraîner, pas une évaluation.

  • Un nouvel énoncé remet la note de sa question à 0 ; afficher la solution ne la change pas.
